# Contributing to presso

Thank you for your interest in presso. The project is currently in an early,
maintainer-led phase, while its architecture and release process are still
changing.

## Code contributions are paused

**External pull requests and patches are not being accepted at this time,**
including documentation changes. This keeps the review workload manageable
while the foundations are established. Unsolicited pull requests may be closed
without review.

Contributions may open up later. This document will be updated when there is a
process and enough capacity to review them. Please wait for that change before
investing time in a contribution intended for this repository.

You are welcome to use, study, modify, and fork the project under its
[Apache 2.0 license](LICENSE), subject to the separate licenses of third-party
components. The contribution policy concerns what is accepted upstream; it
does not restrict those license permissions.

## Bug reports and feedback

Bug reports and feedback from test installations are welcome through
[GitHub Issues](https://github.com/Hinkolas/presso/issues). Search existing issues
first, and include:

- The release or commit you tested and your host OS, architecture, and Docker version.
- Steps to reproduce, expected behavior, and what actually happened.
- Relevant error messages or job logs, with credentials and private data removed.

Please use disposable sites for reproductions. All versions before v1.0.0 are
experimental prereleases, and production workloads are not recommended.
Reports do not carry a response-time or implementation commitment.

For feature ideas, check [ROADMAP.md](ROADMAP.md) first. A suggestion is welcome,
but it does not establish a delivery date or an invitation to submit a patch.

## Security reports

Security reports remain welcome. Follow [SECURITY.md](SECURITY.md) and use the
private reporting channel instead of a public issue.
